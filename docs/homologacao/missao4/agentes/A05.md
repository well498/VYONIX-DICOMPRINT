### 1.1 Como o menu é montado (evidência)
- Rotas da SPA (hash) e permissões: `web/src/app.tsx:24-43`. Um item aparece se `me.permissions` contém **alguma**
  das permissões da rota (`app.tsx:80-81`). "Administração VYONIX" também exige `organization.kind === "operator"`.
- `me.permissions` = lista de permissões **sem unidade** (`vyonix/auth/service.py:80`, `sorted(self.grants)`): papel
  numa só unidade libera o menu inteiro daquela permissão. O back-end é quem restringe por unidade.
- Papéis padrão: `vyonix/modules/manifest.py:328-346`; modelos opcionais: `manifest.py:298-313`. Curingas (`*`,
  `clinical.*`) são expandidos ao gravar o papel (`auth/service.py:101-111`).
- Rota sem permissão digitada na barra (ex.: `#/usuarios`): a SPA mostra silenciosamente a 1ª tela permitida
  (Início), sem mensagem (`app.tsx:82`).

## 2. Roteiro de inspeção visual (para o coordenador, na interface real)

### 2.1 Preparação e regras de evidência (sem tokens/senhas)
1. Use **um navegador/perfil separado por usuário** (ex.: Edge = admin; Chrome perfil "demo" = usuário em teste).
   Janelas anônimas do mesmo navegador compartilham o cookie: entrar com outro usuário encerra a sessão anterior.
2. Primeiro acesso de cada usuário demo cai na tela "Defina sua senha" (`access.tsx:53-76`). Capture a tela **vazia**
   (antes de digitar) e a mensagem de erro de senha fraca, nunca com campos preenchidos visíveis. Não fotografe a
   chave do segundo fator nem os códigos de recuperação (`access.tsx:93-105`), se aparecerem.
3. Capturas: no Chrome/Edge use DevTools → modo dispositivo (Ctrl+Shift+M) e o comando "Capture screenshot"
   (Ctrl+Shift+P). Ele captura só a área da página, sem o painel do DevTools. **Não** capture as abas Network,
   Application ou Console (o JSON de `/auth/me` traz o campo `csrf`; os cabeçalhos trazem `X-CSRF-Token` e o
   cookie de sessão).
4. Não use "Redefinir senha" em Usuários para gerar evidência: ele abre `window.prompt` com a senha **em texto
   visível** (`users.tsx:49`). Não passe o mouse sobre o link "Se o Weasis não abrir, clique aqui" nem o copie: o
   `weasis://` contém um código de acesso de uso único (`vyonix/pacs/external.py:103-108`).
5. Não clique em ações de escrita sem confirmação durante a inspeção visual (lista em 3.4): Desabilitar módulo,
   Desativar unidade/usuário, Remover regra de encaminhamento, Autorizar imagens retidas, Concluir/Cancelar exame.
6. Nome dos arquivos de evidência: `A05_<perfil>_<rota>_<largura>.png` (ex.: `A05_financeiro_central_390.png`).
   Anote, para cada captura: usuário demo, data/hora, versão mostrada em Sistema (quando visível).
