# ADR-0010: Windows 7: sem suporte na plataforma; edição legada do Print só sob demanda comprovada

* **Situação:** Aceita
* **Data:** 2026-10-23

## Contexto

O Prompt Mestre §20 pede avaliar o Windows 7 sem comprometer a segurança dos módulos modernos. Fatos: o Python 3.9+ não roda no Windows 7; o Qt 6 exige Windows 10; o PostgreSQL 17 não tem binários oficiais para Windows 7; o Windows 7 não recebe atualizações de segurança desde janeiro de 2020 (ESU encerrado em janeiro de 2023).

## Decisão

A plataforma e o DICOM Print atual exigem Windows 10 1809+ / 11 / Server 2019+ (`MinVersion=10.0.17763` nos instaladores). Uma **edição legada isolada** do Print (Python 3.8 + Qt 5.15, sem plataforma, sem rede de entrada além do DICOM) só será construída se houver cliente com equipamento que não possa migrar, com aprovação comercial e documentação própria.

## Consequências

Nenhum componente moderno é rebaixado. O instalador recusa o Windows 7 com mensagem clara.

## Alternativas consideradas

Suportar Windows 7 em todo o produto — rejeitada (critério eliminatório de segurança, §7).

## Condição para rever

Contrato com cliente que dependa de Windows 7 (exige aprovação, §59).
