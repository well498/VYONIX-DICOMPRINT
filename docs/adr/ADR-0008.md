# ADR-0008: Empacotamento com PyInstaller (onedir)

* **Situação:** Aceita
* **Data:** 2026-10-21

## Contexto

O Print já é compilado e validado com PyInstaller no CI do Windows.

## Decisão

CORE, worker e DEPLOY em `VyonixPlatform.spec` (dois executáveis num só COLLECT); instalador Inno Setup.

## Consequências

Reaproveita o pipeline validado.

## Alternativas consideradas

Nuitka/MSI — sem ganho que justifique trocar.
