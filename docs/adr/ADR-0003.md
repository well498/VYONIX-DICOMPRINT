# ADR-0003: Windows primeiro no EDGE; Linux a partir da Fase 3

* **Situação:** Aceita
* **Data:** 2026-10-21

## Contexto

O Print imprime pelo spooler/GDI do Windows e a base de clientes usa Windows.

## Decisão

EDGE em Windows 10 1809+/11 e Windows Server 2019+. Linux só para unidades sem impressão, a partir da Fase 3. Nuvem em Linux.

## Consequências

Um só alvo de instalação nas Fases 1–2. Ver ADR-0010 para Windows 7.

## Alternativas consideradas

Linux desde a Fase 1 — rejeitada: dobraria a matriz de testes sem cliente que precise.

## Condição para rever

Cliente com servidor Linux e impressão por outro equipamento.
