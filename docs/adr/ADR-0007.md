# ADR-0007: Nuvem multiclínica com tenant_id e FORCE ROW LEVEL SECURITY

* **Situação:** Aceita
* **Data:** 2026-10-21

## Contexto

Um banco por clínica multiplica migrações, backups e conexões.

## Decisão

Todas as tabelas com `tenant_id`; RLS forçado; o papel da aplicação não é dono das tabelas; teste automatizado tenta ler outro tenant em cada versão.

## Consequências

Isolamento verificável; mesmo esquema permite banco dedicado se o contrato exigir.

## Alternativas consideradas

Banco por clínica — rejeitado.

## Condição para rever

Exigência contratual de isolamento físico.
