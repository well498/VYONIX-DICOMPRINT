# ADR-0009: SQLAlchemy 2 + Alembic com um ramo de migração por módulo

* **Situação:** Aceita
* **Data:** 2026-10-21

## Contexto

Cada módulo precisa evoluir o próprio esquema sem depender da ordem dos outros.

## Decisão

SQLAlchemy 2; Alembic com ramos por módulo (`heads(prefix)`), separador de caminho próprio.

## Consequências

Módulos independentes.

## Alternativas consideradas

Migrações SQL manuais (como no Print) — mantidas só no Print até a integração.
