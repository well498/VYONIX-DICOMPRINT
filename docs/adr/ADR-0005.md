# ADR-0005: Interface web única (React + TypeScript); Qt do Print mantido na transição

* **Situação:** Aceita
* **Data:** 2026-10-21

## Contexto

Acesso remoto, portais de paciente e médico e interface unificada não são possíveis em Qt.

## Decisão

Web em React + TypeScript (esbuild), servida pelo CORE. O aplicativo Qt do Print continua até existir tela web equivalente para cada função.

## Consequências

Nenhuma parada do Print. Custo: duas interfaces durante a transição — por isso o Print recebe correções de usabilidade (ADR-0013) em vez de reescrita.

## Alternativas consideradas

Manter o Qt como interface principal — rejeitada.
