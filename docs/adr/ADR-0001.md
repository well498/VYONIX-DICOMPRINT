# ADR-0001: Monorepo a partir do repositório do DICOM Print

* **Situação:** Aceita
* **Data:** 2026-10-21

## Contexto

O DICOM Print está em homologação com testes e verificações no Windows. A plataforma precisa compartilhar licenciamento (`vyonix_protocol`, `vyonix_commercial`) e o pipeline de compilação.

## Decisão

Um único repositório. `vyonix/`, `vyonix_deploy/` e `web/` ficam ao lado de `app/`; o código do Print não é movido até a integração (Fase 3), porque `app/` é referenciado pelos specs do PyInstaller, pelo instalador, pelo CI e pelos caminhos de dados.

## Consequências

Histórico preservado e um só lugar para o licenciamento. Custo: o CI precisa separar os pipelines (Print, plataforma, DEPLOY, interface).

## Alternativas consideradas

Repositório novo com o Print como dependência — rejeitada: duplicaria o licenciamento e o pipeline sem ganho funcional.
